# HYBRID CHALLENGE LOG — PWA Setup

Upload these files to the ROOT of your GitHub repository:

- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Keep your existing config.js unchanged.

After committing, wait for Netlify to show the deploy as Published.

Android:
Open the site in Chrome → menu → Install app / Add to Home screen.

iPhone:
Open the site in Safari → Share → Add to Home Screen.

Future normal UI/menu changes:
Usually update index.html only.

Future PWA/icon/cache changes:
Update the relevant files and increase CACHE_NAME in service-worker.js:
hybrid-challenge-log-v1 → v2 → v3 ...
